# Icons

`burrow.svg` is a placeholder icon generated programmatically. It will be replaced with a proper design before release.

If you're a designer and want to contribute a proper icon, we're looking for:
- A minimal flat-style mole or burrow illustration
- Works at small sizes (16×16, 22×22, 48×48)
- Looks good on both light and dark system trays
- SVG format preferred
